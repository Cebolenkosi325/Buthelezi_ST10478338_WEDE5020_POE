## Project Overview
Sunrise Bakery is a fictional bakery website built for the WEDE5020 Portfolio of Evidence.
The project has 3 parts: HTML structure (Part 1), CSS styling (Part 2), JavaScript (Part 3).

## Website Goals and Objectives
- Increase local brand awareness and attract new customers.
- Generate online enquiries and orders for custom cakes and catering.
- Showcase the daily menu and seasonal specials.

## Key Features
- Homepage with hero section and call to action
- About Us page with history, mission and vision
- Products page with bread, cakes, pastries and catering
- Enquiry page with custom order form
- Contact page with address, map and contact form
